# Awesome Downloader — showcase video

A 4:52 product film (1920×1080, 60 fps, H.264 + AAC) and a 2:12 square cut for
social, built with [Remotion](https://www.remotion.dev) from the **real app**:
every app screen in it is captured from Awesome Downloader itself.

| File | What it is |
|---|---|
| `final.mp4` | The film |
| `social-1x1.mp4` | The 1:1 social cut |
| `poster.jpg` / `poster.png` | Thumbnail / poster frame |
| `embed.html` | Copy-paste embed for the website (SEO metadata included) |
| `FEATURE_MANIFEST.md` | Every feature, colour and claim, audited from the code |
| `SCENE_LIST.md` | Storyboard with timestamps |
| `QA_REPORT.md` | What was checked, what was found, what was fixed |

## Edit the words or the timing

Everything editable is in **`src/config.ts`**: each scene's eyebrow, title,
caption, length (`seconds`) and the moments inside it (`beats`, in seconds),
the sound effects (`sfx`), and the links. Card copy (the six "why" cards, the
three steps, …) is in `COPY` in the same file.

After an edit:

```bash
npm run audio      # the sound effects follow the timings
npm run qa         # reading-time check, copy check, link check
npm run render     # -> final.mp4
```

`npm run dev` opens Remotion Studio to scrub through the film live.

## Music

The soundtrack is generated from scratch (`scripts/soundtrack.mjs`): an
ambient bed and UI sounds, no samples, nothing copyrighted, normalised to
−14 LUFS. To use your own track, put it at `public/music.mp3`, set
`MUSIC = "music.mp3"` in `src/config.ts`, then `npm run audio` and
`npm run render` — the sound effects stay, your track replaces the bed.

## Re-capturing the app

```bash
npm run capture
```

Runs `capture/capture.py` with the app's own virtual environment
(`../.venv312`). It builds the app exactly as `main_qt.py` does, in a
throwaway test profile (nothing of yours is read or written), fills it with
made-up content (`capture/synth.py` draws the pictures; the browser opens
our own page at `clips.example`, served from a local folder by WebView2) and
saves every state at 2× into `public/captures/`, plus `meta.json` with the
pixel rectangle of each widget the film points at. Windows on screen open
for a few minutes while it runs. Paths that would show your user folder are
shown as `C:\Users\You` in every picture.

The captures, the soundtrack and the rendered videos aren't kept in git (they're
large and regenerated by the scripts): after a fresh clone run `npm install`,
`npm run capture` and `npm run audio` before `npm run render`.

## All scripts

| Script | Does |
|---|---|
| `npm run dev` | Remotion Studio (preview) |
| `npm run capture` | Re-capture the app (`public/captures/`) |
| `npm run audio` | Regenerate `public/audio/soundtrack*.wav` |
| `npm run render` | Render `final.mp4` |
| `npm run render:social` | Render `social-1x1.mp4` |
| `npm run poster` | Render `poster.png` and `poster.jpg` |
| `npm run stills` | QA stills (start, middle, end of each scene) + contact sheets in `out/` |
| `npm run qa` | Pacing, copy, links, and the rendered files' fps, sync, loudness |
| `npm run typecheck` | TypeScript check |

## How it's built

```
src/
  config.ts          copy, timings, links, music -- the one file to edit
  tokens.ts          the app's colours, fonts, easings, layout
  components/        Backdrop, Stage (window frame + camera), Callout, Cursor,
                     Keycaps, Caption, TitleBlock, Badge, CornerTag, Wordmark,
                     SceneShell (enter/exit), Icon
  scenes/            Opening (hook, logo, why, tour), Features (the tour of the
                     app), Closing (themes, differentiators, performance, open
                     source, quick start, outro)
  Showcase.tsx       the film;  Social.tsx  the 1:1 cut;  Poster.tsx
capture/             the app capture (Python) and the demo site
scripts/             soundtrack, stills, QA
```

Callouts and the cursor are laid out in the captures' own pixels (from
`meta.json`), so they stay on the right widget while the camera moves.

Requirements: Node 22+ (type-stripping imports `config.ts` in the scripts),
ffmpeg on `PATH`, and for capture the app's `.venv312`. Remotion downloads
its own headless Chrome on first render. Remotion is free for individuals
and small teams; larger companies need a licence (remotion.dev/license).
